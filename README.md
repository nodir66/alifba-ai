## 🌟 Qo‘shilgan Barcha Yangi Imkoniyatlar:

1. **📑 PDF Fayllarni Word (.docx) ga Xatosiz O‘tkazish:**
   - PDF hujjatidagi barcha jadvallar, sarlavha, matnlar va rasmlarni aniq saqlagan holda tahrirlanuvchi Word (.docx) formatiga aylantiradi.
   - Xohlasangiz faqat Wordga o‘tkazish yoki Wordga o‘tkazish bilan birga tilini/alifbosini ham o‘zgartirish mumkin!

2. **🔀 To‘liq Tanlash Imkoniyati (Yo‘nalishlar):**
   - **Кирилл ➔ Yangi Lotin:** `Ў, Ғ, Ш, Ч` ➔ `Ö, Ğ, Ş, Ç`
   - **Eski Lotin ➔ Yangi Lotin:** `O', G', Sh, Ch` ➔ `Ö, Ğ, Ş, Ç`
   - **Кирилл ➔ Amaldagi/Eski Lotin (1995):** `Oʻ, Gʻ, Sh, Ch`
   - **Lotin (har qanday) ➔ Кирилл:** `Ö/O' ➔ Ў, Ğ/G' ➔ Ғ, Ş/Sh ➔ Ш, Ç/Ch ➔ Ч, Yu ➔ Ю, Ya ➔ Я...`
   - **Aralash matn ➔ Yangi Lotin**

3. **🇷🇺 ⇄ 🇺🇿 Rus tili va O‘zbek tili Xatosiz Tarjima:**
   - **Ruscha ➔ O‘zbekcha:** Word, Excel, PDF va matnlarni sun’iy intellekt orqali xatosiz o‘zbek tiliga tarjima qilish.
   - **O‘zbekcha ➔ Ruscha:** O‘zbekcha hujjat va matnlarni to‘liq rus tiliga tarjima qilish.
